# Cyber AI Agent

Cyber AI Agent is a layered, explainable machine-learning system for network
traffic threat detection and post-hoc explanation. It combines traditional
classifiers (XGBoost), transformer-based text models (BERT), and a
denoising autoencoder to detect anomalies from flow-export CSVs, then fuses
model outputs and generates human-readable explanations for flagged events.

This repository contains training notebooks, model artifacts, and a
FastAPI-based inference service for integration and demonstration.

**Quick Start**

- Prerequisites: Python 3.8+ (3.11 recommended), Node.js (for frontend), git.
- Create and activate a virtual environment (Windows PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

- Install Python dependencies:

```bash
python -m pip install -r backend/requirements.txt
```

**Run backend (development)**

- From workspace root:

```bash
python -m uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

- Or from `backend/` directory:

```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

API docs: `http://localhost:8000/docs`

**Run frontend (development)**

- From `frontend/`:

```bash
cd frontend
npm install
npm run dev
```

**Notebooks & training**

- Training notebooks live under `backend/notebooks/`.
- Trained artifacts are in `backend/trained_models/` and expected by the inference pipeline.
- Note: TensorFlow may not be installed in your environment on Windows; AE notebooks include import guards. Install `tensorflow-cpu` if you need to run autoencoder training.

**Files of interest**

- `backend/app/main.py`: FastAPI app entrypoint
- `backend/app/pipeline.py`: Orchestrates layers (ingestion → preprocessing → models → fusion)
- `backend/app/layers/`: Layer implementations used at runtime
- `backend/notebooks/`: Training notebooks (preprocessing, xgboost, bert, autoencoder, ensemble)

**Troubleshooting**

- If `tensorflow` fails to import on Windows, try:

```bash
python -m pip install tensorflow-cpu
```

or install the appropriate Microsoft Visual C++ Redistributable.
